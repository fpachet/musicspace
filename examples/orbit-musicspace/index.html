About this experiment & a 60-second walkthrough

A short demonstration

  1. Start sound and drag Wet. Dry compensates.
  2. Disable the balance and compare independent control.
  3. Enable the spring. Pull Cutoff and release.
  4. Start the sweep. Watch Resonance respond.
  5. Undo the last gesture, or save the complete session.

Built from the real packages

Uses Yann Orlarey’s Orbit UI, the standalone MusicSpace engine and a compiled Faust DSP running in an AudioWorklet. Everything loads locally; no account or microphone is needed.

The Orbit copy has a small experimental extension for solving geometry before values are emitted. The host records whole-scene undo, including dynamics. Preset recall restores the exact sound and resets spring rest length; a recalled dry/wet mix becomes balanced on the next edit.
